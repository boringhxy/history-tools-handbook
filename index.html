01

研究范围与阅读方法

本手册把软件、平台、数据库、标准与专题智能体分层处理。23 个核心平台用于理解方法链条，其余条目用于扩展检索和项目选型。云四库为目录外新增核心平台；原始 115 项目录中已有“云四库智能问答小程序”条目，目录记录保持不变。

选择史料工具不应从“哪个最强”开始，而应从材料形态、研究问题、人工校订能力、可迁移格式、权利约束和长期保存责任开始。相同工具在古籍、手稿、旧报刊和现代文本上的表现可能完全不同。

建议先用“生命周期”确定自己目前所处环节，再用比较矩阵识别平台边界，最后阅读档案卡片中的工作流、局限与证据要求。

证据原则：自动 OCR、标点、翻译、实体抽取与大模型问答都属于候选结果。正式论证必须能回到原图、原文、版本、页码和人工修订记录。
使用顺序
  1. 1界定材料
    古籍、手稿、地图、网页、音视频或通用文本
  2. 2确定环节
    采集、识别、清洗、标注、建库、分析、出版或保存
  3. 3比较边界
    部署、开放性、人工成本、导出格式与证据链
  4. 4设计退出
    先确认数据能否批量导出、备份、复核和迁移
02

史料处理生命周期

工具不是孤岛。真正可复核的数字史料项目，需要让稳定标识符、出处、版本和修订记录贯穿全部环节。

01 · INPUT采集

影像、文本、网页、音视频与权利信息

02 · RECOGNIZE识别

OCR、HTR、版面与时间转写

03 · CLEAN清洗

纠错、去重、规范化与版本校勘

04 · ANNOTATE标注

实体、概念、关系、时间与空间

05 · MODEL建库

元数据、关系模型、知识库与馆藏

06 · ANALYZE分析

文本、网络、空间与解释循环

07 · PUBLISH出版

数字版本、展览、查看器与公众传播

08 · PRESERVE保存

校验和、保存包、迁移与访问控制

06

技术标准与数据互操作

标准不是平台，也不计入 115 项工具数量。它们决定了数据能否跨工具流动、重现并在平台退出后继续使用。

转录—标注—出版

TEI

文本结构、校勘、实体与编辑责任的 XML 编码规范

衔接：Transkribus/eScriptorium → TEI Publisher；Recogito 可导出 TEI

采集—对读—出版

IIIF

跨机构图像传输、展示、清单与注释互操作规范

衔接：馆藏/Omeka S → Mirador/Recogito

识别—交换—保存

METS/ALTO

打包数字对象与表达 OCR 版面、坐标及文本的标准组合

衔接：OCR 平台 → 数字馆藏/保存系统

保存

PREMIS

记录数字保存对象、事件、代理与权利的元数据标准

衔接：Archivematica → AIP/DIP 与审计轨迹

采集—保存

WARC

封装网页请求、响应与相关资源的网页存档格式

衔接：Webrecorder → 保存仓储/Archivematica

07

四种典型研究组合工作流

单一平台很少覆盖全部环节。以下组合强调“入口—整理—分析/发布—保存”的分工关系，可作为项目设计的起点。

01

古籍数字整理与学术版本

  1. 材料入口识典古籍 / eScriptorium
  2. 整理与建模OpenRefine + TEI
  3. 分析与发布TEI Publisher + Mirador

以底本与版本说明为中心，OCR只是初稿；源 TEI、影像定位和校订记录必须同步保存。

02

档案照片与人物关系研究

  1. 材料入口Tropy + Transkribus
  2. 整理与建模OpenRefine + INCEpTION
  3. 分析与发布Heurist + Gephi + QGIS

从照片级出处进入转录、实体校订、关系/空间建模；网络图和地图结论必须回链原页。

03

口述史与音视频档案

  1. 材料入口ELAN
  2. 整理与建模受控词表 + 质性编码
  3. 分析与发布AtoM / Omeka S

知情同意、访问级别和敏感片段处理优先；媒体、EAF、摘要和公开副本分层管理。

04

网页与 born-digital 史料

  1. 材料入口Webrecorder
  2. 整理与建模WARC/WACZ 质检 + 元数据
  3. 分析与发布Archivematica + AtoM

记录捕获环境与缺失项，保存哈希和采集日志；访问副本、法律限制与长期保存副本分离。

08

研究空白与方法论问题

文献综述不应停留于功能罗列。真正值得推进的议题，是工具如何改变证据生产、解释责任、可复现性和知识基础设施。

01

评测对象错位

通用 OCR/NLP 指标常来自现代、干净语料，难以代表异体字、破损页、旧报刊和多栏版式。

研究议程建立按年代、载体、版式和损坏程度分层的开放测试集。

02

人工校订不可见

平台宣传强调自动化，但真实项目的校对、裁决和返工成本往往没有系统报告。

研究议程报告人工时、错误类型、复核比例、模型版本与修改日志。

03

工具链断裂

识别、标注、建库、分析、出版和保存常分别完成，标识符与出处在交换中丢失。

研究议程以稳定 ID、TEI/IIIF/PREMIS/WARC 和数据字典贯穿生命周期。

04

可复现性不足

很多研究只给出最终图表，没有保存参数、词表、过滤阈值、随机种子和失败样本。

研究议程把数据、操作历史、环境、脚本和负面结果视为研究成果。

05

平台依赖与退出机制

云平台迁移、收费变化、停服或授权调整会影响长期可访问性。

研究议程优先评估批量导出、开放格式、本地备份和替代迁移路径。

06

伦理与权利滞后

公开平台可能包含隐私、敏感群体、受限档案或未授权图像。

研究议程把权利、同意、文化协议和分级访问纳入项目设计而非发布末端。

09

文献综述写作提纲

提纲以方法链和知识生产问题组织材料，避免按软件名称逐项介绍。每一节都可用核心平台作案例，再以 115 项目录补充领域广度。

  1. 一、问题界定

    区分工具、平台、数据库、标准与专题智能体；说明“史料处理”涵盖的材料和生命周期。

  2. 二、资料数字化与机器识别

    比较印刷 OCR、HTR、古籍版面和多语种识别，讨论真值、错误率和人工校订。

  3. 三、清洗、标注与知识组织

    从表格规范化、语义标注到关系数据库/知识图谱，比较数据模型与解释框架。

  4. 四、计算分析与解释

    讨论文本、网络、空间和质性分析如何形成证据，以及图形化带来的解释风险。

  5. 五、数字出版与公共史学

    比较数字版本、馆藏、IIIF 查看、展览和公众众包的传播与学术责任。

  6. 六、长期保存与互操作

    以 TEI、IIIF、METS/ALTO、PREMIS、WARC 讨论跨平台交换、版本和退出机制。

  7. 七、国内平台的场景化发展

    重点比较吾与点、识典古籍、南京大学数智文献处理平台与云四库如何回应中文古籍、近现代文献、知识服务和空间分析需求。

  8. 八、研究空白与评价框架

    提出准确性、人工成本、透明度、可迁移性、伦理、保存与可复现性评价维度。
