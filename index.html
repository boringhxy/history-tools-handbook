      自行接入 AI

      ✳

      平台对比无需 API。需要进一步讨论研究任务时，可按教程接入自己的模型账户，费用由接入者承担。

      查看 API 接入教程

      本网站不提供共享 API 或免费问答额度。浏览、比较、复制和打印资料无需模型账户；只有你主动连接并提交问题时，才会请求自己配置的模型。

      1. 取得完整项目源码，在 DeepSeek 开放平台创建 API Key 并开通计费。下载单个 HTML 可以浏览，但运行问答还需要项目中的 server 和 data 目录及 Python 3.9 以上版本。
      2. 在终端进入项目根目录。以下示例用于 macOS 的 zsh；输入 API Key 时终端不显示字符，不要把密钥写进网页或提交到 Git。
      read -s 'OPENAI_API_KEY?请输入自己的 API Key：'
export OPENAI_API_KEY
export OPENAI_BASE_URL='https://api.deepseek.com'
export OPENAI_MODEL='deepseek-flash'
export WEB_SEARCH_ENABLED=0
export COOKIE_SECRET="$(python3 -c 'import secrets; print(secrets.token_hex(32))')"
# 以下为应用预算示例，单位美元；请按所选模型价格核算。
export APP_DAILY_BUDGET_USD=1
export REQUEST_MAX_COST_USD=0.10
python3 -m server.app --port 8765

      保持终端运行，打开 http://127.0.0.1:8765/，然后点击下方“连接我配置的服务”。直接打开 HTML 文件不能连接问答。项目不会自动读取 .env 文件。

      上面的密钥仅保存在当前终端环境；关闭终端后需重新配置。长期使用时，请用服务管理器安全保存配置，并保持 COOKIE_SECRET 和配额数据库持久化。

      模型按实际输入、输出 token 及所用工具计费；输入还包含平台资料和部分历史对话。示例中的单次 0.10 美元是网站预留额度，不是供应商单价，也不是供应商强制扣费上限。失败或超时仍会占用网站预留额度；实际账单以模型平台为准。请同时设置供应商提供的可用额度控制，并查看官方价格。

      也可接入 OpenAI：将接口地址改为 https://api.openai.com/v1，并填写自己的 OpenAI API Key 与支持 Responses API 的模型名称。初次连接保持搜索关闭。API 与 ChatGPT 订阅分别计费，详见官方价格。

      此版本后端仍设每个匿名身份每天最多 5 轮等应用限额。自建服务的限额属于接入者的设置，不表示网站赠送额度。公开部署需要独立后端和 HTTPS；GitHub Pages 仅托管静态页面，不能运行 Python。更多部署配置见源码中的 server/README.md。

      尚未连接自己的服务。基础对比无需 API，可直接使用。
