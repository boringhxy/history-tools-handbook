01

关于本指南

这份指南收录数字人文研究中可用的平台与工具，帮助读者了解它们能做什么、适合哪些史料，以及怎样参与具体的研究工作。

从平台信息到使用方法

面对一份扫描古籍、一组档案照片或一批期刊文章，找到工具只是开始。还需要判断：它能否处理这类材料，结果如何核查，输出能否用于下一步工作。本指南围绕这些问题组织平台介绍、功能比较和流程参考。

内容面向希望了解数字工具的历史学研究者、学生及相关人文学科读者。你可以按平台查功能，也可以按研究环节或史料类型寻找使用方法；不必按章节从头读到尾。

阅读口径：平台功能依据公开资料整理，具体功能、资源范围、费用与访问权限请以平台当前说明为准。文中会区分已找到官方依据的功能、尚待确认的能力，以及供参考的方法建议。流程案例不等于已经完成的跨平台实验。

02

如何使用本指南

先确定你现在要解决的问题，再选择入口。比较功能之后，建议继续查看平台档案中的材料要求、限制和导出方式。

还不知道有哪些工具

进入平台目录，用关键词、史料类型或处理环节缩小范围。目录同时收录数据库、研究平台和技术组件，筛选后先看条目的定位，不把它们当作同一类产品比较。

已有几个备选平台

进入核心平台比较查看26个平台的功能覆盖，再点击平台名称阅读档案。“强”“部分”等标记表示功能定位，不表示识别准确率或研究质量；需要更具体的中文史料任务时，可看五平台专题。

想知道一项研究怎样推进

进入研究流程参考，查看通用流程或专题案例，关注每一步的输入、人工工作和输出。涉及多个平台时，先确认文件格式与导出内容，再用少量材料试走一遍。

手上已有具体史料

进入史料处理参考，选择古籍异本、报刊、档案、日记书信等材料类型。先明确比较单位和解读问题，再看平台分工；同样的文本差异，在不同史料中可能有不同含义。

第一次使用：选一小份有代表性的材料 → 保留来源与原件 → 试用并人工复核 → 检查能否导出结果及修订记录 → 再决定是否扩大处理规模。功能证据、互操作标准和资料来源见方法与来源。
03

AI时代的史料处理流程参考

AI可以参与识别、整理、检索和分析，但各环节仍需保留材料出处与人工判断。下面是一条可按项目取舍、往返修订的流程，不要求使用全部工具，也不要求将每一步交给AI。

01确认来源与范围

确定材料出处、版本、卷页、年代、权利和研究范围。

AI可辅助：辅助整理已有书目信息，提出检索词和待查线索。

人工核查：逐项核实书目与链接；未核到的文献保持待查，不将模型生成的书目当作来源。

02数字化与识别

将影像、手稿或录音转为可检索文本，保留原页或时间位置。

AI可辅助：辅助OCR、手写识别、版面分析及语音转写。

人工核查：检查缺页、漏行、栏序、异体字、人名和数字；识别文本必须能回到原件。

03校订与整理

区分原始转录、人工校订和为检索制作的规范化文本。

AI可辅助：提出纠错、去重、标点和格式统一的候选修改。

人工核查：保留原字与修改记录；不因词句陌生就改成常见表达，也不无说明地合并异体字。

04检索与标注

按研究问题标记人物、地点、时间、概念及待考段落。

AI可辅助：提出实体、关系、主题或相似段落候选，辅助建立初步索引。

人工核查：结合上下文核对同名异人、年代与指代；明确标注规则，允许不确定和多种解释。

05建库与关联

将文本、出处和标注组织成可查阅、可修订的数据。

AI可辅助：辅助转换格式、草拟字段和整理关联候选。

人工核查：检查字段含义、记录标识与来源是否保留；推测关系与史料明言的关系分开记录。

06分析与解释

结合细读开展词频、文本比较、空间或关系分析，检验研究问题。

AI可辅助：协助探索模式、归纳候选主题和生成分析代码。

人工核查：检查样本、缺失、参数和代码结果；相似不等于引用，共现不等于因果，模型归纳需回到具体史料。

07引用与呈现

将研究论证、引文和图表对应到可查证的材料与处理过程。

AI可辅助：辅助草拟说明、整理已有引文和调整表达。

人工核查：逐条核实引文、页码及图表，说明必要的AI使用与人工复核；研究者对最终表述负责。

08保存与复用

保存原始材料、校订文本、标注、处理参数及输出文件。

AI可辅助：辅助编写数据说明、检查文件清单和转换格式。

人工核查：检查导出是否完整、备份能否打开、权限是否合适；分享链接不能替代本地保存。

贯穿全程的做法：原件与处理结果分开保存；记录工具、模型或版本、日期及关键设置；说明哪些内容经人工核查，哪些仍有疑问。涉及未公开档案或个人信息时，先确认授权与平台数据处理规则，再决定是否上传。

具体的平台组合见研究流程参考；不同材料的解读问题见史料处理参考。这里提供总体路径，不能替代史料批判和具体研究方法。

五条流程：材料如何变成研究成果

找古籍 · 读书影 · 做整理

识典古籍

从古籍资源发现进入阅读；具备整理权限时，再进入图像识别与校订生产。

材料与权限
平台古籍正文与书影；整理入口使用有权处理的古籍图像。 阅读与整理是两个入口。阅读平台公开开放；整理任务、材料上传和发布按实际项目权限确认。
  1. 输入：资源与检索词在阅读入口按分类、时代与关键词检索输出：候选书目与命中段落
  2. 输入：候选段落切换图文对照，核对底本和校订状态输出：可回溯的原文摘录
  3. 输入：有权整理的图像／粗校文本在整理入口进行OCR、文字对勘、标点与实体校订输出：待审核的整理文本
  4. 输入：整理文本人工审核后按项目权限发布；核实可带走的数据输出：文本成果与出处说明
人工检查点
区分粗校与精校；核对异体字、避讳字、缺损、标点及底本。年代筛选不可直接当作精确成书年代。
成果与导出
阅读产生带版本说明的摘录；整理产生经校订的文本。批量全文、影像、实体和校订记录的导出格式均需按项目确认。

同一事件，四种材料：先保留说法，再分析差异

以下为虚构教学例句，不是历史引文。假设材料均围绕某次集会：不能把四种说法合并成模型生成的单一“事实摘要”。

史料与示例说法优先如何解读需要核验什么
报刊社论：“此次集会系暴动。”“暴动”先作为作者／刊物的命名与立场，分析栏目、受众及报道框架。与消息报道分开；核对刊登日期、消息来源、转载关系。
机构报告：“到场者三百余人。”作为特定机构在特定程序中的数量陈述，记录统计口径和报告目的。谁计数、何时计数、是否转报，及初报与后报的变化。
当日日记：“闻街市聚众，未往。”是同期转述，并明确作者未到场；可研究信息传播和个人反应。保留“闻”“未往”，不能抽取成作者亲见或参与。
晚年回忆：“我们当时都明白其意义。”区分当时经验与晚年自我解释；考察记忆重构和叙事共同体。事件／讲述时间差、采访提问、编辑痕迹及同期材料。

抽取字段也应随之改变：事件、陈述内容、陈述主体、史料类型、文类／栏目、事件时间、记录时间、出版／访谈时间、亲见／转述／推测、原文位置、互证材料、研究者判断。矛盾说法先分别保存，再讨论其来源与可比性；不采用多数投票决定史实。

非纯文本材料边界：历史地图、照片、录音和碑面图像还需检查比例尺、图例、构图、拍摄／测绘环境、声音与物质载体。五平台中的文本处理只覆盖部分环节；图像细读、GIS配准和音视频转写应连接本手册已有Mirador、QGIS、ELAN等工具。

方法参考：美国国会图书馆：史料分析的作者、目的与受众；报刊分析导引；美国国家档案馆：原始材料与历史解释。上述七类细分与平台分工是本手册据此作出的编辑性综合；DEDU多语种实例见官方公开项目。

案例 01 · 示范流程

古籍整理与版本比较

识典古籍 → DEDU 对读

材料与目标
同一作品两种有明确版本说明、允许使用的文本，配少量书影。示范取10个段落，包含缺文或异体字；不将样本当作性能评测。
  1. 输入：底本与段落清单在识典查找文本和书影；有整理权限时校订输出：校订文本与版本、卷页记录
  2. 输入：经复核的两份文本规划对应单位并在DEDU编辑对应结构输出：可导航的平行文本
  3. 输入：对应内容人工标记异文、解释缺段与一对多关系输出：异文记录与判断依据
  4. 输入：复核成果按项目权限分享，核查可下载成果输出：公开／受限链接与本地保存清单
人工介入与失败情况
检查异体字、标点、脱衍倒误与文本重排；区分OCR错误、版本异文与编辑改动。佛典异译另按语义、译者和底本系统比较，不能套用逐字校错。自动对齐能力尚未确认。
数据交接 · 未验证直连
识典 → DEDU：传递正文、版本和卷页；可能丢失字图坐标、校订日志。未验证直接导入，必要时手工编辑。
成果清单
校订样例、对应关系、异文表、底本说明和复核记录。

案例 02 · 示范流程

近代期刊专题研究

南大平台 → 出处表 → DocuSky

材料与目标
以“教育”相关概念为演示主题，自行限定刊物与年份；实际范围取决于南大平台可访问资源。示范整理20条候选记录，不能据此宣称资源覆盖率。
  1. 输入：主题、刊名与年份核对南大平台资源目录与实际可访问范围输出：可检索范围和缺期资料说明
  2. 输入：关键词、异称与范围使用实际可用的检索与筛选，记录条件及日期输出：候选文章与检索日志
  3. 输入：候选文章核对刊名、卷期、日期、页码及原页依据输出：去重后的文章出处表
  4. 输入：有权取得的文本与出处核对导出条件；转换DocuXML后试建库输出：专题语料及检索分析记录
人工介入与失败情况
原页定位、文章级筛选和下载尚待界面验证；资源未收录不等于概念未出现。转载去重和语料规模会影响频率解释。消息、社论、广告、读者来信分别标注；频次、立场与事实判断分别报告。
数据交接 · 未验证直连
南大 → DocuSky：仅传递获准取得的材料，字段映射后转换DocuXML；未验证直接导出／直连。无法取得全文时先做出处表。
成果清单
检索日志、文章清单、卷期页码、排除理由、语料范围说明。

案例 03 · 示范流程

人物与事件信息抽取

吾与点 → 人工复核 → DocuSky

材料与目标
来源明确且允许处理的10段短文本。字段设为人物、事件、时间、地点、原文、出处、复核状态；加入同名人物与模糊日期样例。
  1. 输入：研究问题与短文本在吾与点定义字段、关系边界和原文出处输出：字段字典及人工示例
  2. 输入：字段与示例配置模型、规则和提示语，小批抽取输出：待复核的数据表与配置
  3. 输入：抽取结果及原文逐条核对实体、时间和关系，记录修改输出：经复核数据与错误类型
  4. 输入：复核数据和配置导出数据与JSON配置；映射DocuXML试建库输出：本地备份、研究库及分析说明

数据交接 · 未验证直连
吾与点 → DocuSky：CSV／JSON先做字段、多值和文献单位映射；关系不一定无损转入。未验证自动直连，保留原始导出与配置。
成果清单
复核数据表、字段字典、JSON配置、修改记录及逐条原文出处。

08

研究空白与方法论问题

文献综述不应停留于功能罗列。真正值得推进的议题，是工具如何改变证据生产、解释责任、可复现性和知识基础设施。

01

评测对象错位

通用 OCR/NLP 指标常来自现代、干净语料，难以代表异体字、破损页、旧报刊和多栏版式。

研究议程建立按年代、载体、版式和损坏程度分层的开放测试集。

02

人工校订不可见

平台宣传强调自动化，但真实项目的校对、裁决和返工成本往往没有系统报告。

研究议程报告人工时、错误类型、复核比例、模型版本与修改日志。

03

工具链断裂

识别、标注、建库、分析、出版和保存常分别完成，标识符与出处在交换中丢失。

研究议程以稳定 ID、TEI/IIIF/PREMIS/WARC 和数据字典贯穿生命周期。

04

可复现性不足

很多研究只给出最终图表，没有保存参数、词表、过滤阈值、随机种子和失败样本。

研究议程把数据、操作历史、环境、脚本和负面结果视为研究成果。

05

平台依赖与退出机制

云平台迁移、收费变化、停服或授权调整会影响长期可访问性。

研究议程优先评估批量导出、开放格式、本地备份和替代迁移路径。

06

伦理与权利滞后

公开平台可能包含隐私、敏感群体、受限档案或未授权图像。

研究议程把权利、同意、文化协议和分级访问纳入项目设计而非发布末端。

09

文献综述写作提纲

提纲以方法链和知识生产问题组织材料，避免按软件名称逐项介绍。每一节都可用核心平台作案例，再以 115 项目录补充领域广度。

  1. 一、问题界定

    区分工具、平台、数据库、标准与专题智能体；说明“史料处理”涵盖的材料和生命周期。

  2. 二、资料数字化与机器识别

    比较印刷 OCR、HTR、古籍版面和多语种识别，讨论真值、错误率和人工校订。

  3. 三、清洗、标注与知识组织

    从表格规范化、语义标注到关系数据库/知识图谱，比较数据模型与解释框架。

  4. 四、计算分析与解释

    讨论文本、网络、空间和质性分析如何形成证据，以及图形化带来的解释风险。

  5. 五、数字出版与公共史学

    比较数字版本、馆藏、IIIF 查看、展览和公众众包的传播与学术责任。

  6. 六、长期保存与互操作

    以 TEI、IIIF、METS/ALTO、PREMIS、WARC 讨论跨平台交换、版本和退出机制。

  7. 七、国内平台的场景化发展

    重点比较吾与点、识典古籍、南京大学数智文献处理平台、DocuSky、DEDU与云四库如何回应中文古籍、近现代文献、知识服务和空间分析需求。

  8. 八、研究空白与评价框架

    提出准确性、人工成本、透明度、可迁移性、伦理、保存与可复现性评价维度。
