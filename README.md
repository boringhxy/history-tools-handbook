面向文史哲研究者的**数字史料研究工作流地图**：把 27 个核心平台、119 项工具、5 项互操作标准与 4 种通用研究流程、3 组专题示范流程，组织成一份可筛选、可离线、可打印的交互式章节手册（单文件）。

> 它不是一张「工具清单」，而是一幅从材料采集到长期保存的完整研究地图——帮助研究者选对工具、走通流程，并让数据不被平台锁死。

## 双平台研究选型助手（2026-10-22）

“平台对比”现在默认进入朱红与暖白的双平台工作台：从 **122项工具与资源**中选择两个，按“确认用途与条件—查找与获取材料—准备自有材料—处理与分析材料—导出与保存成果—核查依据与限制”六个研究阶段，并排查看13个维度及已有专题任务证据。122项由原119项目录加云四库、DEDU、Texta组成；原目录和27份核心档案继续保留，数量口径不同。MARKUS、COMPARATIVUS独立归属能力。

新维度依据研究者的实际选型：平台的主要用途；提供的材料类型、覆盖范围、呈现形式、检索阅读、获取权限；支持处理的自有材料、处理工具、准备要求、操作流程、成果导出；平台使用条件及功能依据与限制。下拉菜单按六个研究阶段列出全部13项维度，可选择单项或恢复全部比较维度。资料库为V2；字段缺失明确待补充，支持处理的材料标签不会转成平台馆藏，公开案例也不等同综合史料库。来源来自现有资料迁移，本轮没有重新核验所有网站的新功能。

支持名称／别名搜索、键盘选择、交换、任务筛选、只看差异、分享链接、复制完整报告和打印。桌面为2:1分栏；手机切换“平台对比／研究助手”。页面只提供双平台对比，旧比较链接统一进入工作台；原始档案保留为资料依据。资料不足明确标注，研究方法建议与官方说明区分，不提供性能排名。

本地预览：在项目目录运行 `python3 -m server.app --port 8765`，打开 [双平台工作台](http://127.0.0.1:8765/#compare)。无需第三方Python依赖。直接打开 `index.html` 可离线使用基础比较。

在线问答需要服务端密钥、模型、稳定Cookie签名密钥和预算配置。未配置、超额或服务不可用时，界面如实提示，基础比较仍可用。问答不模拟回答；每匿名浏览器每天5轮，另有IP／频率／持久预算控制。详见 [问答服务部署说明](server/README.md) 和 [环境配置示例](server/.env.example)。已完成一次本地DeepSeek真实问答验证；GitHub Pages不包含本地问答配置，公开服务仍需另行部署与验收。

GitHub Pages只支持静态部分。要公开问答，应在同一站点通过HTTPS反向代理提供 `/api/*`，或把完整页面与服务一并部署到同一域名。保留 `comparison-api-base` 元信息为空即可走同源接口；只有确认同站点Cookie和CORS配置后才填写其他API地址。不要直接把GitHub Pages和不相关域名服务拼接后声称匿名额度已可靠启用。

维护与验证：

```sh
python3 scripts/build_comparison.py
python3 scripts/build_comparison.py --check
python3 -m unittest discover -s tests -v
node tests/test_comparison.cjs
node tests/test_navigation.cjs
```

源文件位于 `comparison/`；构建将样式、脚本和资料全部内嵌到 `index.html`。不要直接编辑生成区。资料来自现有原始JSON块，`data/platforms.json`供服务端使用；新增功能声明应先补充来源，方法建议不能标记为实测。浏览器验收运行 `node tests/test_comparison_browser.cjs`，需安装Playwright及Chrome；可用 `PLAYWRIGHT_MODULE`指定依赖路径，`PREVIEW_URL`指定预览地址。

## 这个项目解决什么

数字人文研究里最实际的四个问题，这里都有一份成体系的答案：

- **这个环节该用什么？** —— 按 8 阶段「史料处理生命周期」定位所处环节，再选对应工具。
- **平台边界与衔接？** —— 27 个核心平台各有一份统一框架的档案，并配比较矩阵。
- **数据如何跨工具流动？** —— 5 项互操作标准保证数据可迁移、可复现。
- **还有哪些方法论之坑？** —— 6 类研究空白 + 8 部分文献综述写作提纲。

## 五平台专题深比（2026-10-19）

新增识典古籍、南京大学数智文献处理平台、DocuSky、吾与点、DEDU对读的12项任务比较，支持任务筛选、关键词查询及最多3个平台并排阅读。专题正文、矩阵与三组示范流程无需JavaScript也可阅读。

- 识典区分公开阅读和项目整理入口；南大保留现有平台身份，深化近代期刊研究核验问题。
- DocuSky提升为核心平台；DEDU作为目录外核心平台新增。核心档案共26个，基础工具目录仍为115项。
- 三组新增流程：古籍整理与版本比较、近代期刊专题研究、人物与事件信息抽取。原有四组通用流程保留。
- 功能依据官方公开说明整理，未登录实测；未知能力标为待确认，跨平台交接标为建议路径，不能当作已经验证的自动直连。
- 打印时专题恢复全部平台及任务；离线可用，外部来源链接需联网访问。

## 按史料区分对读与解释

五平台专题补充七类材料：古籍异本、佛典异译、近代报刊、机构档案、日记书信、回忆录与口述史、地方志族谱碑刻。每类说明比较单位、解读重点、语境、推断边界及五平台的方法性分工；补充同一事件四种史料的虚构教学示例。研究方法建议与平台已核实功能分开，不能据此推定资源收录或专门功能。

## 首页与章节导航

首页仅保留简介和“汇聚119个数字人文平台”“最新更新：2026-10-19”两条信息，深蓝主色配细网格与光晕；顶部目录切换七个章节：首页、使用指南、平台目录、核心平台比较、研究流程参考、史料处理参考、方法与来源。每次只显示当前章节；原有hash链接仍能进入对应内容，支持浏览器前进、后退与章节分享。

- 核心平台比较包含27平台比较、平台档案、五平台专题三个子栏目；方法与来源有独立子栏目。
- 七类史料及教学示例分别阅读；七个研究流程每次显示一个。
- 平台档案独立搜索与材料筛选，每页6项；工具目录每页12项。两组条件相互独立。
- 支持打印当前章节（含子栏目与匹配结果）或完整手册；完整打印包括全部115项工具。打印后恢复筛选、分页与说明展开状态。
- 保留单文件离线结构；关闭JavaScript时静态内容退回完整文档阅读。

## 资料口径

本手册基于一份收录 119 项史料处理工具的工作簿整理而成，核心平台信息优先引用官网、官方文档与机构页面。

- 本仓库仅发布整理后的最终网页，不公开原始 Excel 工作簿。
- 平台能力以「强 / 部分」标注功能覆盖程度，不构成质量或市场排名。
- 自动处理与平台宣传不能替代具体材料上的人工复核与独立评估。
