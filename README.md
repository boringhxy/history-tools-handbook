# 文史哲史料处理工具｜交互式学术手册

这是一个面向文史哲研究者的可筛选学术单页，包含 23 个核心平台档案、工作流、比较矩阵、研究空白、文献综述提纲和官方来源，并支持离线打开与打印。

## 内容范围

- 23 个核心平台，包括吾与点、识典古籍、南京大学数智文献处理平台和云四库等中文文史平台。
- 115 项原始工具目录；云四库平台是目录外新增核心平台，原始目录内已有“云四库智能问答小程序”条目，目录数量保持不变。
- 史料处理生命周期：采集、识别、清洗、标注、建库、分析、出版和保存。

## 在线访问

- ChatGPT Sites：https://history-tools-handbook.berrydrake12.chatgpt.site
- GitHub Pages：https://boringhxy.github.io/history-tools-handbook/

## 使用方法

打开 `index.html` 即可离线使用。页面支持关键词、层级、生命周期、材料类型和核实状态筛选；浏览器打印功能可生成适合保存或批注的版本。

如需发布到自己的 GitHub 仓库，请按 `UPLOAD_GUIDE.md` 操作。压缩包已经包含 GitHub Pages 自动发布工作流。

## 资料口径

基础资料来自一份包含 115 项史料处理工具的工作簿。本仓库不公开原始 Excel，只发布由其整理形成的最终网页。核心平台优先引用官网、官方文档和机构页面；自动处理和平台宣传不能替代具体材料上的人工复核与独立评估。
