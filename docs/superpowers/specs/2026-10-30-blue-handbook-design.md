# 蓝色工作台风格统一设计

用户已于 2026-10-30 确认推荐方案：其余六个栏目采用蓝色版双平台工作台风格，现有双平台对比页保持原样。开发在本地 `feat/blue-handbook-style` 分支完成，不合并 main、不推送、不发布。

## 设计选择

选择整站其余六栏一次统一，而非逐页采用互不相关的视觉方案；对比页作为已确认的参照，不重新设计。保留各页适合其内容的布局，以共同的色彩、边框、字体、标签和控件建立一致性。

## 视觉规范

- 深蓝 `#0B2748`：主标题、关键操作、深色重点区域。
- 中蓝 `#175FA8`：活动导航、链接、交互强调。
- 浅蓝 `#E8F0F8`：标签、步骤标题和选中背景。
- 细边框 `#D3DFEB`：内容分隔与表单边界。
- 冷白纸面 `#F5F8FC`：页面底色。
- 白色 `#FFFFFF`：内容与表单背景。
- 沿用已有 Noto Sans SC 正文和 Noto Serif SC 标题；中文正文约 16px、行高 1.85，注释不承担主体内容。
- 采用对比页的直角、清晰细边框、局部阴影、紧凑标题与分组阅读；不把长文章强行改为比较表格。
- 首页保留封面功能与当前文案，使用深蓝重点区、冷白纸面与结构化边界；不新增装饰图片。

## 页面范围

首页、使用指南、平台目录、研究流程参考、史料处理参考、方法与来源，以及这些页面下现有子栏目。目录卡片、筛选区、分页、流程卡片、史料列表与方法卡片统一视觉。各页保留原有内容、锚点、导航和功能。

比较工作台及其生成源文件不修改；后端、资料数据和问答逻辑不修改。本次不顺带修复前次审计中的服务错误和旧入口问题。

## 实现边界

在 index.html 添加一个有明确标记的独立内嵌样式区，限定为非比较页及屏幕媒体，保留离线单文件结构。使用 body 的当前栏目状态隔离样式，避开比较区生成标记。优先通过现有元素与语义类完成，无额外运行时依赖。

## 验收

1. 非比较的六个栏目均为蓝色系，主要内容框为直角，活动状态清晰。
2. 对比页样式、比较源文件和数据保持基线。
3. 320、390、768、1440px 无整页横向溢出，长标题与中文正文自然换行。
4. 保留搜索、分页、章节切换、轮播、子栏目、基础对比、离线与打印。
5. 现有 41 项 Python 测试、52 项 JavaScript 断言及构建检查通过；新增浏览器验收覆盖视觉隔离和关键交互。
6. 本地分支提交，保留工作目录供预览；main 与原开发分支均不修改。
