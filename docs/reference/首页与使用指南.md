## 关于本指南

这份指南收录数字人文研究中可用的平台与工具，帮助读者了解它们能做什么、适合哪些史料，以及怎样参与具体的研究工作。

### 从平台信息到使用方法

面对一份扫描古籍、一组档案照片或一批期刊文章，找到工具只是开始。还需要判断：它能否处理这类材料，结果如何核查，输出能否用于下一步工作。本指南围绕这些问题组织平台介绍、功能比较和流程参考。

内容面向希望了解数字工具的历史学研究者、学生及相关人文学科读者。你可以按平台查功能，也可以按研究环节或史料类型寻找使用方法；不必按章节从头读到尾。平台功能依据公开资料整理，具体功能、资源范围、费用与访问权限请以平台当前说明为准。文中会区分已找到官方依据的功能、尚待确认的能力，以及供参考的方法建议。流程案例不等于已经完成的跨平台实验。

<a id="how-to-use"></a>

## 如何使用本指南

先确定你现在要解决的问题，再选择入口。比较功能之后，建议继续查看平台档案中的材料要求、限制和导出方式。

### 还不知道有哪些工具

进入[平台目录](../../index.html#catalog)，用关键词、史料类型或处理环节缩小范围。目录同时收录数据库、研究平台和技术组件，筛选后先看条目的定位，不把它们当作同一类产品比较。

### 已有几个备选平台

进入[平台对比](../../index.html#compare)，从122项工具与资源中选择两个，查看定位、材料、能力、使用条件及来源。可按研究任务筛选或只看差异，再向研究助手描述具体目标。

### 想知道一项研究怎样推进

进入[研究流程参考](%E7%A0%94%E7%A9%B6%E6%B5%81%E7%A8%8B%E5%8F%82%E8%80%83.md#workflows)，查看通用流程或专题案例，关注每一步的输入、人工工作和输出。涉及多个平台时，先确认文件格式与导出内容，再用少量材料试走一遍。

### 手上已有具体史料

进入[史料处理参考](%E5%8F%B2%E6%96%99%E5%A4%84%E7%90%86%E5%8F%82%E8%80%83.md#material-reading)，选择古籍异本、报刊、档案、日记书信等材料类型。先明确比较单位和解读问题，再看平台分工；同样的文本差异，在不同史料中可能有不同含义。

**第一次使用：**选一小份有代表性的材料 → 保留来源与原件 → 试用并人工复核 → 检查能否导出结果及修订记录 → 再决定是否扩大处理规模。功能证据、互操作标准和资料来源见[方法与来源](%E6%96%B9%E6%B3%95%E4%B8%8E%E6%9D%A5%E6%BA%90.md#standards)。

<a id="lifecycle"></a>

## AI时代的史料处理流程参考

AI可以参与识别、整理、检索和分析，但各环节仍需保留材料出处与人工判断。下面是一条可按项目取舍、往返修订的流程，不要求使用全部工具，也不要求将每一步交给AI。

<a id="flow-carousel"></a>

01**确认来源与范围**

确定材料出处、版本、卷页、年代、权利和研究范围。

**AI可辅助：**辅助整理已有书目信息，提出检索词和待查线索。

**人工核查：**逐项核实书目与链接；未核到的文献保持待查，不将模型生成的书目当作来源。

02**数字化与识别**

将影像、手稿或录音转为可检索文本，保留原页或时间位置。

**AI可辅助：**辅助OCR、手写识别、版面分析及语音转写。

**人工核查：**检查缺页、漏行、栏序、异体字、人名和数字；识别文本必须能回到原件。

03**校订与整理**

区分原始转录、人工校订和为检索制作的规范化文本。

**AI可辅助：**提出纠错、去重、标点和格式统一的候选修改。

**人工核查：**保留原字与修改记录；不因词句陌生就改成常见表达，也不无说明地合并异体字。

04**检索与标注**

按研究问题标记人物、地点、时间、概念及待考段落。

**AI可辅助：**提出实体、关系、主题或相似段落候选，辅助建立初步索引。

**人工核查：**结合上下文核对同名异人、年代与指代；明确标注规则，允许不确定和多种解释。

05**建库与关联**

将文本、出处和标注组织成可查阅、可修订的数据。

**AI可辅助：**辅助转换格式、草拟字段和整理关联候选。

**人工核查：**检查字段含义、记录标识与来源是否保留；推测关系与史料明言的关系分开记录。

06**分析与解释**

结合细读开展词频、文本比较、空间或关系分析，检验研究问题。

**AI可辅助：**协助探索模式、归纳候选主题和生成分析代码。

**人工核查：**检查样本、缺失、参数和代码结果；相似不等于引用，共现不等于因果，模型归纳需回到具体史料。

07**引用与呈现**

将研究论证、引文和图表对应到可查证的材料与处理过程。

**AI可辅助：**辅助草拟说明、整理已有引文和调整表达。

**人工核查：**逐条核实引文、页码及图表，说明必要的AI使用与人工复核；研究者对最终表述负责。

08**保存与复用**

保存原始材料、校订文本、标注、处理参数及输出文件。

**AI可辅助：**辅助编写数据说明、检查文件清单和转换格式。

**人工核查：**检查导出是否完整、备份能否打开、权限是否合适；分享链接不能替代本地保存。

**贯穿全程的做法：**原件与处理结果分开保存；记录工具、模型或版本、日期及关键设置；说明哪些内容经人工核查，哪些仍有疑问。涉及未公开档案或个人信息时，先确认授权与平台数据处理规则，再决定是否上传。

具体的平台组合见[研究流程参考](%E7%A0%94%E7%A9%B6%E6%B5%81%E7%A8%8B%E5%8F%82%E8%80%83.md#workflows)；不同材料的解读问题见[史料处理参考](%E5%8F%B2%E6%96%99%E5%A4%84%E7%90%86%E5%8F%82%E8%80%83.md#material-reading)。这里提供总体路径，不能替代史料批判和具体研究方法。
