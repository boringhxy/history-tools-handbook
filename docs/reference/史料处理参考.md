# 史料处理参考

<a id="page-reading"></a>

<a id="material-reading"></a>

先辨史料，再做对读

### 同样是文本差异，不同史料要问不同的问题。

先区分三层：**原件与文本的差异**（字形、版本、OCR）、**叙述的差异**（立场、语境、记忆）和**研究解释的差异**（研究者的归类与推断）。平台可以帮助定位、并置和整理证据，不能自动决定哪一种历史解释成立。

以下“史料×平台”是依据既有能力提出的方法性使用建议，不代表平台已收录这些材料，也不新增未经核实的功能声明。先核对资源、权限和格式，再采用建议流程。具体功能证据请查看“平台比较”中的任务矩阵。

<a id="reading-edition"></a>

#### 古籍异本与传抄本

#### 比较对象与单位

同一作品的不同抄本、刻本、整理本；以字句、段落和批校为单位。

#### 解读重点

异文如何产生？是抄刻、避讳、删改、标点还是后人整理造成？

#### 必须保留的语境

记录版本、刊刻／抄写年代、卷页、递藏与校订责任；作品成书时间与现存版本时间分列。

#### 不能直接推出

先区分底本文字、编辑改动与OCR错误；有差异不等于某本必错，也不能仅凭相似度判定版本谱系。

##### 五平台如何参与 · 方法建议

* **识典古籍**从已收录古籍定位底本与书影；整理入口校对或文字对勘，权限另核。
* **南大平台**古籍异本并非已确认的专门入口；有相关近代整理资料时仅作旁证。
* **DocuSky**建议按版本分别建文献，保留异体原文与规范化副本；词频比较先控制文本范围。
* **吾与点**建议抽取异文位置、字形及校记，保留原句；模型给出的“正字”不得直接替换底本。
* **DEDU**建议组织异本平行段落及对应依据；对应关系和版本价值由研究者判断。

<a id="reading-translation"></a>

#### 佛典异译与跨语种平行文本

#### 比较对象与单位

同经异译、梵汉藏巴利平行文本及注疏；以语义单位、术语和段落为单位。

#### 解读重点

差异来自底本系统、译者用语、翻译策略还是注疏解释？

#### 必须保留的语境

记录语种、经号、译者、翻译年代、底本／校订本以及注疏层次；区分原典、译文与解释。

#### 不能直接推出

不同语言不能强求逐字对应；缺译、重排与一对多不一定是文本损坏。术语同译也不必然概念相同。

##### 五平台如何参与 · 方法建议

* **识典古籍**可在已收录佛部材料中查汉文原文；不据此推定有梵藏全文或自动跨语种对齐。
* **南大平台**整体跨语种检索可供线索发现；佛典具体资源与语言覆盖未核实。
* **DocuSky**建议不同语种分文献建库，分别设置分词与标记；不能直接比较原始词频。
* **吾与点**建议建立原语—译语术语表并记录语境与不确定性；自动翻译不能充当校勘本。
* **DEDU**公开项目已有多语种对读例；建议人工确定语义段与术语对应，勿写成自动翻译功能。

<a id="reading-periodical"></a>

#### 近代报纸与期刊

#### 比较对象与单位

同一事件的不同刊物、同刊不同时期；区分消息、社论、广告、读者来信与转载。

#### 解读重点

报道如何选择事实、命名事件和组织立场？某个词在何种栏目与受众中传播？

#### 必须保留的语境

记录刊名、卷期、日期、版面／栏目、作者与受众；把事件日期、发稿／刊登日期分开。

#### 不能直接推出

报道数量不等于事件发生率或社会共识；转载不是独立证词；“暴动”等命名不能直接作为研究分类。

##### 五平台如何参与 · 方法建议

* **识典古籍**可核对报道引用的古典语句；不当作已确认的近代报刊检索主入口。
* **南大平台**作为近代材料发现入口；先核实刊物／年份范围，期刊字段筛选和原页定位仍待核。
* **DocuSky**建议以文章为文献，按刊物、栏目、时间分组比较，并记录收录及缺期。
* **吾与点**建议分列事件事实、报道措辞、引用来源与作者判断，勿压成一列“事件结论”。
* **DEDU**建议并排展示不同报道与段落；不能按字面差异自动裁定哪篇更真实。

<a id="reading-archive"></a>

#### 行政、司法与机构档案

#### 比较对象与单位

同一事务的呈文、批示、调查、判决与附件；以案卷关系、文书类型和形成顺序为单位。

#### 解读重点

谁有权记录与归类？制度程序怎样筛选信息？不同文书说法为何变化？

#### 必须保留的语境

记录全宗／案卷／件号、形成机构、成文日期、文种、流转及附件；制度形成过程与事件时间分开。

#### 不能直接推出

行政分类不等于当事人自我认同；判决、供述与调查报告证据性质不同；缺件不能简单视为未发生。

##### 五平台如何参与 · 方法建议

* **识典古籍**古籍中的制度文本可作背景参照；不等于现代档案馆藏或案卷管理功能。
* **南大平台**仅在已收录且获准访问的档案／汇编中检索；原始案卷关系与全文获取条件须另核。
* **DocuSky**建议将文书及案卷ID分列，保留上下级、附件与流转关系；文本统计回到程序语境。
* **吾与点**建议抽取机构、文种、发受文者、程序动作、断言主体与出处，分清报告与裁决。
* **DEDU**建议组织不同文书相关段落互证；展现说法变化，不能抹平文种与程序地位。

<a id="reading-diary"></a>

#### 日记与书信

#### 比较对象与单位

同一人在不同日期的记录、不同通信者对同一事件的描述；以条目、封信和通信关系为单位。

#### 解读重点

作者当时知道什么、向谁叙述、为何记录？私人表达与公开叙述有何差异？

#### 必须保留的语境

记录写作／寄送／收信日期、收件人、原件与后期编订关系；保留删改、缺页及传闻标记。

#### 不能直接推出

同期记录也不自动等于亲见；“听说”不能改写成目击。未提及某事不能直接推出作者不知情或不在场。

##### 五平台如何参与 · 方法建议

* **识典古籍**在已收录日记、文集或书札中查文本与底本；原件和整理本区别需自行核查。
* **南大平台**机构说明包含日记等材料；具体文本、版本与检索范围仍需逐项核实。
* **DocuSky**建议按条目／封信建库，区分作者、收件人、时间和知情方式，再比较叙述变化。
* **吾与点**建议抽取亲见／转述／推测、情绪及通信对象；情绪标签属分析结果，需给依据。
* **DEDU**建议把同期叙述并排阅读；对应的是主题或事件，不应强行按句一一对齐。

<a id="reading-memory"></a>

#### 回忆录、口述史与事后追述

#### 比较对象与单位

同期记录与事后回忆、不同访谈与修订版；以叙述片段、访谈轮次和录音时间段为单位。

#### 解读重点

事件后来如何被记忆、解释与重组？访谈提问和后期编辑怎样参与叙述形成？

#### 必须保留的语境

记录事件时间、讲述／写作时间、访谈者、提问、编辑出版时间及版本；声音停顿与语气不能仅靠转写替代。

#### 不能直接推出

记忆偏差与事实错误需核查，也可成为记忆研究对象；对事实可靠性的判断与对记忆意义的解释分别报告。

##### 五平台如何参与 · 方法建议

* **识典古籍**可找与追述相关的古典文献背景；录音转写与时间轴另配音视频工具。
* **南大平台**机构说明包含回忆录；其原始访谈、录音和后期编订链不作默认存在。
* **DocuSky**建议以片段建库，分列事件时间与讲述时间；分析记忆主题时保留访谈情境。
* **吾与点**建议分开抽取当时经历、事后评价与采访者提问；保留音频时间码字段及人工复核。
* **DEDU**建议对照同期记录与后期版本的相关片段；不是已核实的音视频转录／同步工具。

<a id="reading-local"></a>

#### 地方志、族谱与碑刻

#### 比较对象与单位

不同修志／修谱版本、地方文献与现场碑刻；以条目、谱系陈述、碑文及载体位置为单位。

#### 解读重点

地方、家族或立碑者如何组织历史、选择人物并建立正统与纪念？

#### 必须保留的语境

记录修纂年代、编者、资助者、体例、谱系代次、碑刻地点及拓本来源；同名异人、地名沿革单独核验。

#### 不能直接推出

谱系陈述不自动等于可证实血缘；后修志与旧志可能承袭；碑文拓片、录文和现代校释不是同一层证据。

##### 五平台如何参与 · 方法建议

* **识典古籍**在已收录方志、文集等找条目与书影；具体族谱／碑刻资源覆盖另核。
* **南大平台**如有相关近代地方材料可作互证；不预设有完整族谱或碑刻专库。
* **DocuSky**建议建人物—地点—时间—来源关联，保留原称与规范ID；空间可视化另核坐标。
* **吾与点**建议提取人物、职官、地名与谱系陈述，给每条关系标注叙述来源和可信度依据。
* **DEDU**建议对照不同修纂版本及录文；图像与碑面细节仍需专门查看器核验。

#### 同一事件，四种材料：先保留说法，再分析差异

以下为虚构教学例句，不是历史引文。假设材料均围绕某次集会：不能把四种说法合并成模型生成的单一“事实摘要”。

| 史料与示例说法 | 优先如何解读 | 需要核验什么 |
| --- | --- | --- |
| 报刊社论：“此次集会系暴动。” | “暴动”先作为作者／刊物的命名与立场，分析栏目、受众及报道框架。 | 与消息报道分开；核对刊登日期、消息来源、转载关系。 |
| 机构报告：“到场者三百余人。” | 作为特定机构在特定程序中的数量陈述，记录统计口径和报告目的。 | 谁计数、何时计数、是否转报，及初报与后报的变化。 |
| 当日日记：“闻街市聚众，未往。” | 是同期转述，并明确作者未到场；可研究信息传播和个人反应。 | 保留“闻”“未往”，不能抽取成作者亲见或参与。 |
| 晚年回忆：“我们当时都明白其意义。” | 区分当时经验与晚年自我解释；考察记忆重构和叙事共同体。 | 事件／讲述时间差、采访提问、编辑痕迹及同期材料。 |

**抽取字段也应随之改变：**事件、陈述内容、陈述主体、史料类型、文类／栏目、事件时间、记录时间、出版／访谈时间、亲见／转述／推测、原文位置、互证材料、研究者判断。矛盾说法先分别保存，再讨论其来源与可比性；不采用多数投票决定史实。

**非纯文本材料边界：**历史地图、照片、录音和碑面图像还需检查比例尺、图例、构图、拍摄／测绘环境、声音与物质载体。五平台中的文本处理只覆盖部分环节；图像细读、GIS配准和音视频转写应连接本手册已有Mirador、QGIS、ELAN等工具。
