# 首页与章节导航实施方案

沿用用户确认的结构：八个顶部目录入口、首页概览、独立史料解读、分组子栏目和分页。保持单HTML离线文件，变更继续提交到已有草稿PR。

1. 用现有HTML内容重组八个章节容器：home、intro、comparison、reading、profiles、catalog、workflows、methods；原有锚点保留，旧链接可以直接进入对应章节。
2. 按用户后续确认精简首页，仅保留简介与两条指定信息，删除统计卡、任务入口和章节卡片。顶部目录固定，并设置当前章节标识。
3. intro包含研究说明／生命周期；comparison包含全局矩阵／五平台深比；methods包含标准／研究空白／综述提纲／来源。每次只呈现一个子栏目。
4. reading一次展示一类史料，另设教学示例入口；workflows一次展示一个流程。关闭脚本时恢复可读完整文档。
5. 平台档案独立搜索与材料筛选，每页6项；工具目录保留现有条件，每页12项。分页后筛选重置到第一页，深链可打开被分页隐藏的平台档案。目录筛选不再隐式影响其他章节。
6. 基于原有hash链接切换章节，支持前进后退和未知锚点回首页。跨章节定位后更新焦点与标题；不把跳转目标留在隐藏容器中。
7. 打印默认当前章节（含子栏目），提供完整手册按钮；分页、章节隐藏与筛选状态不应导致完整打印缺少内容，打印后恢复屏幕状态。
8. 测试：先验证纯路由和分页边界；再验证页面数据与内部链接；浏览器检查首页、八目录、旧深链、档案／目录分页、独立筛选、史料／案例切换、前进后退、键盘与窄屏；打印采用样式检查，未生成分页PDF时明确限制。

修改文件：index.html、README.md、tests/test_handbook.py、新增tests/test_navigation.cjs、docs/navigation-plan.md、docs/verification.md。保持现有目录与平台事实内容。


## 七栏目架构

首页 → 研究入门 → 平台目录 → 核心平台比较 → 研究流程参考 → 史料处理参考 → 方法与来源。核心平台比较包含25平台比较、平台档案、五平台专题三个子栏目，原平台档案与平台深链接保持可访问。
